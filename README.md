# 水与活字

一个作品集网站。

开场全黑，一条白线从画面中点向两侧画开（它也是加载进度）。摄像机从斜上方 45° 看着画面正中的一只酒坛，白线藏在坛后。水位在坛腹深处，斜看时被坛颈挡住，首页看不到坛里。点击酒坛，白线从两端向中间收拢、藏进坛后，摄像机沿圆周升到坛口正上方，这才望见深处一汪亮水；再前推，穿过幽暗的坛颈，水面铺满画面。水里浮着几个明朝体活字，每个字里半透明地填着一件作品。

- 鼠标划过水面会留下涟漪；活字随水波起伏，被手带起的水流轻轻推开；字里的作品画面跟着鼠标同幅移动，再缓缓回正。
- 活字处在几层不同的深度：最大与最小只差 10%，透明度差 30%。越深的字越虚，水波折射也越明显。
- 点击一个字：字浮上水面、移到中央放大，笔画像墨一样洇开，露出作品画面。画框形状跟着画面走（竖图像立轴、宽图像手卷、方图像斗方）。镜头先看全貌，再逐条移到每条线索对应的位置；每条线索是一句毛笔短句点题、几行宋体注释写具体做法，旁边是技术栈与一句话简介。
- 潜入的终点与水面场景逐像素重合，镜头和交互之间没有切换的痕迹。

## 两种水

`src/content/works.js` 里的 `site.water`：

- `'clear'` 清水（默认）。取“庭下如积水空明，水中藻、荇交横，盖竹柏影也”：偏蓝的青，中间透亮、近坛壁渐深，水底有晃动的光纹和交横的竹影；活字像沉在水里的实物，越深越被水色笼住，并在水底投下影子。界面文字换成深墨蓝。
- `'night'` 夜水。近乎全黑的深水，活字是发着微光的象牙色。

不改代码也能临时对比：网址后面加 `?water=night` 或 `?water=clear`。

## 运行

```bash
npm install
npm run dev       # 开发，http://localhost:5173
npm run build     # 构建到 dist/
npm run preview   # 预览构建结果
```

`dev` 和 `build` 之前会自动运行 `npm run fonts` 裁剪字体。

## 作品

编辑 `src/content/works.js`。现在是三件真实作品（运动社交平台「步」、企微客服 Agent「智」、轨道测量 App「嵌」）。运动社交平台与企微客服 Agent 的截图是本地部署后用模拟数据重新截的，不含任何生产数据；轨道测量 App 的截图来自星岛之谜导出的脱敏版本。

```js
{
  id: 'sport',
  char: '步',                         // 浮在水里的活字（单字）
  title: '运动社交平台',
  year: 2026,
  role: '全栈负责人',
  stack: ['uni-app', 'Vue', 'Spring Boot', 'MySQL'],
  summary: '一句话说清这是什么、你负责什么',
  cover: '/works/sport.webp',         // 作品画面；有录屏时改成 video: '/works/sport.mp4'
  tone: '#d39a52',                    // 灰度截图按这个颜色做双色调
  lines: [                            // 点开后逐条出现的线索
    {
      brush: '步数只认服务端的账',     // 毛笔短句，十几个字以内
      note: '具体做法和数字……',        // 宋体注释
      view: [0.3, 0.17, 1.8],          // 截图上的取景：x、y（左上角为原点，0～1）与放大倍数
    },
  ],
  link: 'https://…',                  // 可选：详细文章或案例
}
```

- 图片和视频放在 `public/works/` 下，路径以 `/works/` 开头。截图的灰阶会自动拉开，再按 `tone` 上色；点开后色调变淡，界面看得清。
- `view` 决定每条线索时镜头停在哪里。调的时候改完刷新页面，点开作品，按下方的“一 二 三”或键盘左右键逐条看。
- 每条停留的时间按注释长短自动计算（8～14 秒），讲完一轮回到全貌，再从头开始。
- 没有画面的作品可以写 `placeholder: 'ink'` 等，使用生成式占位画面（`ink` `light` `dream` `wind` `lantern` `bloom` `moon`）。
- 活字建议选明朝体收录的字。Shippori Mincho 收录的是日文字形，简体专用字会自动退回思源宋体，`npm run fonts` 会提示哪些字缺失。
- 站点标题、坛上斗方的字在同一文件的 `site` 里；界面上的其他文字都在 `src/content/ui.js`。

改完内容后重新运行 `npm run dev` 或 `npm run fonts`，字体会按新的用字重新裁剪。

## 字体

三款字体都是 SIL Open Font License 1.1，可免费商用、可嵌入网页；授权文本在 `fonts-src/`。

| 用途 | 字体 |
| --- | --- |
| 活字 | Shippori Mincho B1 ExtraBold（しっぽり明朝 B1，带活版印刷的晕墨效果） |
| 毛笔短句、斗方 | 志莽行书 Zhi Mang Xing |
| 界面文字 | 思源宋体 Noto Serif SC（可变字重） |

`scripts/build-fonts.mjs` 只保留页面实际用到的字，输出到 `src/fonts/`，由 Vite 打包并加 hash。整站不依赖任何外部 CDN 或 Google Fonts，国内可以直接访问。

## 目录

```
src/
  main.js            场景流转：开场 → 酒坛 → 潜入 → 水面 ⇄ 作品
  content/           作品数据与界面文字
  jar/               酒坛：轮廓、程序化釉色贴图、灯光、摄像机路径、白线
  water/             水面：波动方程模拟、活字距离场、活字着色器、布局
  media/             作品画面：图片 / 视频 / 生成式占位
  ui/                提示、题签、线索、截图导览
scripts/build-fonts.mjs
fonts-src/           字体源文件与授权
public/works/        你的作品素材
```

## 常用的调整点

| 想改的 | 位置 |
| --- | --- |
| 酒坛占画面的比例（默认 30%） | `src/jar/JarScene.js` 的 `JAR_SCREEN_HEIGHT` |
| 酒坛的形状、水位 | `src/jar/JarScene.js` 的 `PROFILE`、`LIQUID_Y` |
| 潜入 / 返回的时长 | `src/main.js` 的 `dive()`、`surface()` |
| 活字深度层级、大小差、透明度差 | `src/water/GlyphField.js` 顶部常量 |
| 涟漪强弱 | `src/water/WaterView.js` 的 `stir()` |
| 字里画面跟随鼠标的手感 | `src/water/WaterView.js` 顶部的 `FILL`：`omega` 越大跟得越紧，`speed` 是目标每秒最多移动的像素；两者越大，急动度越高 |
| 墨晕扩散的节奏 | `src/water/GlyphField.js` 的 `open()` / `close()` |
| 清水 / 夜水的配色 | `src/water/themes.js` |
| 竹影的构图 | `src/water/bamboo.js` |

开发时可以在控制台用 `__hz.dive()`、`__hz.openWork(0)`、`__hz.closeWork()`、`__hz.surface()` 直接跳到各个场景。

## 性能

- 最高按 2 倍像素比渲染。若 GPU 持续跟不上（每帧超过 11 毫秒），每次降 0.25 倍，最低 1 倍。判断依据是 GPU 计时（Chrome / Edge），不是帧率，所以浏览器自己限帧（比如 Safari 低电量模式锁 30 帧）不会被误判成卡顿。
- Retina 屏不开多重采样抗锯齿：字形、白线都在着色器里自己抗锯齿，坛身边缘在 2 倍像素下也足够平滑。
- 酒坛在远处时，坛中的水面按 1/4、1/2 分辨率渲染（带 mipmap）；推近后才切到与屏幕等大的一张，保证交接无缝。
- 生成式占位画面每 4 帧刷新一次；点开后的“视频”按 30 帧刷新。换成真实视频后这部分开销就没有了。

开发时可以在控制台用 `__hz.bench('water')`、`__hz.bench('jar')` 测每帧的实际耗时（毫秒，含 GPU）。

## 浏览器

需要 WebGL2（近几年的 Chrome、Edge、Safari、Firefox 都支持）。不支持时会显示一份纯文字的作品列表。系统开启“减少动态效果”时，转场会缩短，活字不再漂移。
